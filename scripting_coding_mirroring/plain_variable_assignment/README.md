# Plain Variable Assignment

Lo script assegna prima il valore `897` alla variabile `a`e poi stampa `The value of "a" is 897.`

Con `let`, alla riga `11`, si permette di eseguire operazioni aritmetiche su `a`, quindi successivamente si stamperà `The value of "a" is now 21.` Se non si usasse `let`, si stamperebbe `The value of "a" is now 16+5.`

Il ciclo `for`, da riga `21` a riga `24`, stampa sulla stessa riga (`-n`) i valori `7 8 9 11`.

Infine, da riga `30` a riga `32`, si stampa `Enter "a" ` e, con il comando `read`, si chiede all'utente un input che verrà memorizzato nella variabile `a`. Viene poi stampato `The value of "a" is now <input_utente>.`
